## 3. NREQ-01 范围门与原生壳处置

`apps/mobile-capacitor` 与 `apps/desktop-tauri` 只有已生成的 Web 静态文件和 `.gitkeep`，未发现可构建的 Capacitor/Tauri 工程清单。处置冻结为：

1. 本 Goal 不维护或交付原生 App，不为这些目录新增功能；
2. 任何报告、README、构建或 UI 不得把它们计为支持平台；
3. PHASE-01 后将其作为隔离或移除候选，实际删除前必须确认没有未跟踪用户资产；
4. `storage-core` 中 Capacitor/Tauri 备份分支不计入 Web/PWA 备份验收，后续可在兼容迁移中下线或封装为未启用适配器。

进入扩张前必须由 EXP-01 完整证明：固定 TXT 经现有 UI 导入、预览、入架、阅读，进度 1 秒内持久化，刷新与真断网仍可读，并能生成最小版本化备份、在隔离副本恢复且逐项一致。任何缺步、伪成功或数据污染都记录 EVID-27；不得用本阶段 7/7 E2E 代替 GATE-01。
