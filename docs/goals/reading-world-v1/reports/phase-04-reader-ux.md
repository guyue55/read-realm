1. 滚动阅读定位到中段，调大字号，切换左右分页，再切回滚动：书签生成的段落/字符锚点保持在当前阅读视野；连续 5/5 通过。

3. 分页中段添加书签，离开该章、刷新并从目录跳回：书签持久化，目标段落/字符所在页可见。
4. `pagehide` 中断与已打开阅读器真断网续读：中断前位置可恢复，`navigator.onLine=false` 且 browser context 真断网时仍可读已缓存正文并继续落盘。
5. 连续滚动跨 11 章后回读：章节 DOM 上限为 3，当前章与语义位置保持。
6. 独立移动触控项目以可信 touch 输入完成左滑分页、页末换章、进度拖动松手提交和设置抽屉点按；`isMobile=true`、`hasTouch=true`、`maxTouchPoints=1`、粗指针均由活体样本记录。
7. 手机底部工具栏、目录/伴读/设置/笔记弹层，以及桌面抽屉：44px 触控门槛、焦点圈定、Escape、焦点归还、安全区和 reduced-motion 均通过；已修复关闭面板后延迟焦点归还抢占新焦点的竞态。
8. 原生 Chrome 独立临时 profile 在后台期间断开 Playwright，窗口真实经历 `normal → minimized → normal`，页面自行记录 `visible → hidden → visible`；字符锚点 320 在 hidden 状态完成落盘，恢复后仍位于可见页，回前台 657ms。
9. 语义重排动作窗口中 Long Task Observer 可用，未观测到 `≥50ms` 样本（`maxLongTaskMs=0`）。该结果只描述此阅读器动作窗口。
