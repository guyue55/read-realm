# PHASE-05 书架、辅助 UI 与单实例共享藏经阁

- Goal ID：GOAL-READING-WORLD-V1
- 阶段 ID：PHASE-05
- 状态：执行中
- 阶段目标：以统一领域入口和共享反馈组件，让 500 本个人书架及辅助功能井然、流畅、单手可用，并交付不干扰本地核心的单实例共享藏经阁。
- 稳定输入：通过 GATE-01 的数据/阅读服务、现有 AppShell/UI tokens 和用户批准的视觉尺度。
- 依赖：PHASE-04 完成且 GATE-01 通过。
- 本阶段改动边界：library/search/notes/settings/public-library 领域与页面、独立公共馆藏 API/Repository/存储、AppShell、共享 UI、同步状态占位和 a11y。
- 本阶段不做：不建立第二套导航/设计系统，不照搬竞品外观，不新增运营统计、勋章或假数据；不做账号/社交、审核、版权投诉/下架、配额、恶意文件隔离或完整审计平台。
- 定向检查：`node scripts/verify-reading-world.mjs --phase 05 --output docs/goals/reading-world-v1/reports/phase-05-library-ui.json`，内部运行 500 本固定种子基准、公共馆藏领域/API/权限测试、GATE-03、`e2e/library-ui.spec.ts`、`e2e/public-library.spec.ts` 和 axe/视口检查。
- 主线门禁：页面只组合领域服务；公共明文域与私有同步密文域不同表、不同接口和不同文案；默认/缺失/无效分享密钥不可写；已加入本地的书不依赖公共服务继续阅读。
- 活体验收：340/390/768/1024/1440/1920 视口完成找书、继续阅读、笔记筛选、设置和返回路径；GATE-03 完成持凭据发布、匿名浏览、加入本地与真断网阅读。
- 失败处理：优先删减信息密度与重复状态；不得用装饰掩盖无数据或失败。
- 回滚方式：组件和领域入口分切片切换；旧页面适配同一服务直到新页面通过，不复制事实源。
- 人工检查点：品牌气质保持，书架层级、状态清晰、单手操作和低干扰各至少 4/5。
- 阶段完成条件：`reports/phase-05-library-ui.json`、`reports/phase-05-ui-score.md`、`reviews/phase-05-ui.md` 与 EVID-06/14/23/55/56/57 候选产物可复算；NREQ-01/07 范围门仍通过。
- 下一入口：PHASE-06 / TASK-0601 审计并重建 PWA 缓存升级契约。

## 工作项
- TASK-0501：抽离书架查询/操作/同步状态领域服务，消除 LibraryDefault 与页面直接全库扫描。
- TASK-0502：统一搜索、笔记和设置的真实数据、空态、错误与危险操作反馈。
- TASK-0503：实现 GATE-03 最小纵切：独立公共馆藏存储与 API、非默认分享密钥上传、匿名分页浏览、复制加入本地、真断网阅读；通过前隐藏扩张入口。
- TASK-0504：扩张藏经阁主功能：直接文件/文件夹上传、服务端维护目录深度扫描并关联原文件、已具备云端正文的个人书架发布、固定分类/标签模板、书籍/维护者/分类/标签视图与检索分页。
- TASK-0505：重排书架、藏经阁和移动导航信息层级，统一共享 UI、焦点、触控和状态组件。
- 用户新增质感检查点：从整体壳层到卡片圆角、间距、阴影、图标笔画、字体层级与文案语气做一致性审查；目标是更圆润自然但不软塌、不堆装饰，保留安静纸感国风基调。动效不能代替图标、字体、文案与层级本身的修正。
- TASK-0506：运行 500 本压力、公共馆藏分页/故障/权限、视口/a11y 回放与独立视觉体验审查，写入 `reports/phase-05-ui-score.md` 和 `reviews/phase-05-ui.md`。
