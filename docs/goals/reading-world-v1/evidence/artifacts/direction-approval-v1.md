## 已批准的方向摘要

1. 产品是单用户、本地优先、可选私有云同步的个人阅读系统；只对标起点、番茄的阅读体验、功能组织与稳定性，不建设内容商城、社交、广告、推荐流或多用户平台。
2. 本 Goal 交付桌面网页、手机网页和可安装 PWA；暂不开发 iOS、Android 原生 App。
3. 默认只同步书架元数据、进度、书签、笔记、设置和文件指纹；书籍全文仅在用户逐书明确开启后端到端加密上传。
4. 同步密钥只在设备端生成和使用；服务端只保存密文。新设备通过恢复码或已授权设备加入；没有恢复码和可用设备时，密文不可恢复。
5. 私有云保留本机直接运行，并提供单机 Docker 自托管，面向 NAS、家庭服务器或个人 VPS；继续使用 SQLite 与挂载目录，不引入 PostgreSQL、Redis、Kubernetes 或官方托管云。
6. 内容导入以用户有权使用的 TXT、EPUB、文件夹和合法 URL 为主；不内置盗版书源，不绕过登录、付费或反爬，不承诺第三方站点自动追更稳定性。
7. AI 默认关闭且不是核心链路；没有 AI、断网或 AI 失败时，导入、阅读、搜索、笔记和同步必须完整可用。内容外发前必须由用户选择范围并预览。
8. 改动 IndexedDB、OPFS、SQLite、同步协议或阅读进度锚点前必须生成可验证备份；迁移必须版本化、幂等、失败可回滚，禁止静默清库。
9. 核心旅程未稳定前暂停新增功能；不稳定实验能力可隐藏但不得删除数据。正式功能包括书架、导入、阅读、搜索、笔记、导入导出、离线和同步。
10. 完整备份包必须有版本、校验清单和公开结构，支持预览、合并或副本恢复及恢复后校验；书签和笔记另提供 Markdown 或 JSON 导出。
11. 压力基线为 500 本书、单本 1 万章、TXT 200MB、EPUB 500MB；中端手机目标为 LCP 不高于 2.5 秒、INP 不高于 200 毫秒、CLS 不高于 0.1；阅读进度操作后 1 秒内可靠落盘。
12. 验收覆盖 Chrome、Edge、Safari、Firefox 桌面端及 Android Chrome、iOS Safari/PWA，并真实回放导入、离线阅读、恢复、备份还原和双端同步。
13. UI 保留安静、柔和、纸感、国风和沉浸基调，不照搬竞品；允许重构信息层级、阅读控件、移动导航、同步状态、设置结构与共享组件，妨碍可读性、性能或操作的装饰可以删减。
14. 在现有 Monorepo 内演进式替换，先建立领域服务、稳定契约和适配器，再逐块切换；只有纵向实验证明模块不可修复时才局部重写，禁止另起长期并存系统或一次性推倒全仓。

## 授权边界

允许在仓库内创建控制包，并按上述方向持续进行可逆的代码、测试、文档与局部架构改动。公开部署、付费服务、删除用户数据、扩大权限、外部消息或其他外部副作用不在本授权内。机制、范围、成本、权限、持久化方式、依赖或故障半径发生实质变化时，本授权失效，必须进入新的控制修订。

## 可推翻条件

真实代码、数据或跨环境回放若证明 REV-0001 的机制无法在不丢失数据、不引入不可接受复杂度或不破坏离线核心的前提下实现，则暂停受影响范围，保留失败证据，并向用户申请新的版本化方向授权。
